PURPOSE
-------
Explains the password reset workflow, secure token generation/hashing, async email dispatch
via `aiosmtplib`, Jinja2 HTML email templating, and FastAPI's `BackgroundTasks` runner.

----------------------------------------------------------------
1. SECURE TOKEN GENERATION & HASHING (auth.py & models.py)
----------------------------------------------------------------
When a user requests a password reset (`POST /api/users/forgot-password`):

1. Generate Secret Token:
   `token = generate_reset_token()` uses `secrets.token_urlsafe(32)` to produce a cryptographically
   secure 32-byte string (e.g. `dGhpcyBpcyBhIHNhbXBsZSB0b2tlbg`).

2. Compute Token Hash:
   `token_hash = hash_reset_token(token)` uses `hashlib.sha256(token.encode()).hexdigest()`.

3. Database Storage:
   The `PasswordResetToken` record is created in PostgreSQL storing:
   - `user_id`: Foreign key link to the user.
   - `token_hash`: SHA-256 string (64 characters).
   - `expires_at`: `datetime.now(UTC) + timedelta(minutes=settings.reset_token_expire_minutes)`.

4. Security Advantage:
   The raw `token` is sent ONLY in the email link to the user. If an attacker dumps the database,
   they only see SHA-256 hashes, which cannot be reversed to construct valid reset URLs.

----------------------------------------------------------------
2. ASYNC EMAIL UTILITIES (email_utils.py)
----------------------------------------------------------------
The `email_utils.py` module handles email formatting and SMTP sending asynchronously:

- HTML Template Rendering:
  Uses `Jinja2Templates` to render HTML email templates from `templates/email/password_reset.html`:
      template = templates.env.get_template("email/password_reset.html")
      html_content = template.render(reset_url=reset_url, username=username)

- Multipart Email Building:
  Uses Python's standard `email.message.EmailMessage`. Sets plain text body and adds alternative
  HTML body (`message.add_alternative(html_content, subtype="html")`).

- Async SMTP Delivery (`aiosmtplib`):
  Sends email without blocking using async I/O:
      await aiosmtplib.send(
          message,
          hostname=settings.mail_server,
          port=settings.mail_port,
          start_tls=settings.mail_use_tls,
          username=settings.mail_username if settings.mail_username else None,
          password=settings.mail_password.get_secret_value() or None,
      )

3. FASTAPI BACKGROUND TASKS (routers/users.py)
----------------------------------------------------------------
Sending emails over SMTP involves network latency (often 1-3 seconds per email).
If executed directly inside the HTTP request route, the client would hang waiting for the SMTP server response.

FastAPI provides `BackgroundTasks` to offload work after returning an immediate HTTP response:

@router.post("/forgot-password", status_code=status.HTTP_202_ACCEPTED)
async def forgot_password(
    request_data: ForgotPasswordRequest,
    background_tasks: BackgroundTasks,
    db: Annotated[AsyncSession, Depends(get_db)],
):
    ...
    # Save reset token in DB
    db.add(reset_token)
    await db.commit()

    # Queue email task to run after HTTP response is sent
    background_tasks.add_task(
        send_password_reset_email,
        to_email=user.email,
        username=user.username,
        token=token,
    )

    return {"message": "If an account exists with this email, you will receive password reset instructions."}

HOW BACKGROUND TASKS WORK:
1. `background_tasks.add_task(...)` registers `send_password_reset_email` and its parameters in an internal queue.
2. The endpoint returns `HTTP 202 Accepted` immediately (within milliseconds).
3. FastAPI executes `send_password_reset_email` asynchronously in the background event loop right after sending the HTTP response payload back to the client.
